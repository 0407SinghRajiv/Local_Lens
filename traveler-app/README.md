# LocalLens Traveler App

Flutter mobile application for traveler experience discovery, itinerary planning, ride booking, and real-time updates.

## Getting Started

### Prerequisites

- Flutter SDK (>= 3.13.4)
- Android Studio / Xcode for emulators and devices

### Setup

```bash
# Install dependencies
flutter pub get

# Run on connected device/emulator
flutter run
```

### Configuration

Copy `.env.example` to `.env` and configure your API endpoints:

```bash
cp .env.example .env
```
