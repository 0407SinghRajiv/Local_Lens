# Itinerary Optimization Engine

**Core Responsibility**: Combine selected candidate experiences with constraints (time windows, user budget, travel duration, routing distances) to build optimal day and multi-day travel itineraries.

### Planned Submodules:
- `time_slotter.py`: Scheduling and duration estimation
- `route_optimizer.py`: Traveling salesperson problem (TSP) / route minimization solver
- `adaptation_engine.py`: Dynamic re-routing when weather/traffic alerts fire
